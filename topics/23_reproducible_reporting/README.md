# Topic 23: Statistical reporting and reproducible analysis

**Course:** BIT 4131 Statistical Computing and Reporting

## 1. Theoretical explanation
A reproducible report combines code, tables, figures and interpretation so anyone can regenerate it from raw data. Key habits: fixed seeds, scripted data cleaning, recorded package versions, and literate programming (R Markdown / Jupyter).

## 2. Mathematical formulation
- No new formulas: the report reuses topics 1-22 (e.g. a $t$-test with a confidence interval and effect size)
- Report each result as: estimate, CI, test statistic, p-value, interpretation

## 3. Worked example
Hand-checkable example (full code in the scripts below).

```text
WORKED EXAMPLE: the reproducibility checklist

 [x] Raw data kept unchanged in data/
 [x] All steps in code (no manual edits)

 [x] Interpretation written next to results
```
